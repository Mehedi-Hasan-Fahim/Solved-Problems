## 📝 Problem Statement
Given an array `arr[]`, your task is to find the minimum and maximum elements in the array.

---

## 💡 Examples

**Example 1:**
- **Input:** `arr[] = [1, 4, 3, 5, 8, 6]`
- **Output:** `[1, 8]`
- **Explanation:** The minimum and maximum elements of the array are 1 and 8, respectively.

**Example 2:**
- **Input:** `arr[] = [12, 3, 15, 7, 9]`
- **Output:** `[3, 15]`
- **Explanation:** The minimum and maximum elements of the array are 3 and 15, respectively.

---

## ⚠️ Constraints
- $1 \leq \text{arr.size()} \leq 10^5$
- $1 \leq \text{arr}[i] \leq 10^9$
